# ELEDOM - Tienda Online de Electrodomésticos

Proyecto de e-commerce desarrollado como aplicación web dinámica, enfocado en ofrecer una experiencia de usuario limpia, intuitiva y adaptable a diferentes dispositivos para la compra de electrodomésticos.

## Características principales
* **Catálogo Dinámico:** Visualización de productos organizados por categorías mediante controladores en PHP.
* **Vista de Detalle:** Página individual para cada producto con información de precio, disponibilidad de stock en tiempo real y opciones de compra.
* **Diseño Responsivo:** Adaptado completamente para dispositivos móviles y de escritorio mediante CSS Flexbox y Grid.
* **Sección de Usuarios:** Interfaz para el registro e inicio de sesión de clientes.

## Tecnologías utilizadas
* **Frontend:** CSS (Estructura modular con Flexbox y CSS Grid), JavaScript.
* **Backend:** PHP (Lógica de vistas y controladores de categorías).
